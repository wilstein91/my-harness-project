# 긴 맥락 재현용 고정 입력

이 파일은 오늘 대화에서 실제로 발생한 불편을 재현하기 위해 만든 요약 fixture다. 원문 대화의 축어록은 아니다. A와 B 조건에 동일하게 제공한다.

## 앞선 대화 요약

- 사용자는 오늘 수업 노드와 강사 필기 기반으로 초보자용 단계별 실습을 요청했다.
- 먼저 할인 함수 수정과 테스트, 컨텍스트 요약 및 새 세션 비교를 실습했다.
- 사용자는 한 번에 요약을 받는 대신 직접 따라 할 다음 단계와 구체적인 경로를 원한다고 여러 번 설명했다.
- assistant는 한 차례 강사 노트의 실습과 다른 `experience.md` 작성 활동을 제안했다.
- 사용자는 교안에 있는 실습을 원하는데 임의 실습을 제안하고 있다고 지적했다.
- 사용자는 추가 내용은 허용하지만, 추가 내용이라고 밝히고 기본 구성은 교과를 따라야 한다고 명확히 했다.
- 이후 사용자는 다음 과제를 요청했고, assistant가 또 교과 실습과 다른 과제를 제안해 정정이 필요했다.
- 사용자는 과제에 GitHub 보고서 제출 형식이 있으므로 임의로 진행하면 안 된다고 바로잡았다.

## 현재 요청에 필요한 수업 발췌

노드 5절은 경험·스킬 축적을 다룬다. 다음 실행에 쓸 경험은 근거를 확인할 수 있고, 필요할 때 다시 불러오며, 다음 행동을 바꾸는 데 적용할 수 있어야 한다.

강사 노트의 명확화 실습은 다음과 같다.
1. 다음 작업에도 쓸 내용만 `.claude/skills/myskill/SKILL.md`에 저장한다.
2. 각 항목에 오류나 테스트 결과 같은 근거와 날짜를 붙인다.
3. 새 세션에서 `/myskill`을 불러왔는지 확인한다.
4. 테스트 실패·오류·사용자 정정 등 확인된 증거가 있을 때만 갱신하고, 폐기 이유와 확인 횟수를 남긴다.
