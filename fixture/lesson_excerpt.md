# 고정 입력: 수업 노트 발췌

## 노드 5절: 경험·스킬 축적

로그를 저장했다고 경험이 쌓인 것은 아니다. 다음 실행에 쓰이려면 원문 기록에서 근거를 확인할 수 있고, 필요할 때 검색되며, 다음 행동으로 바꿔 적용할 수 있어야 한다.

남기는 형태로 원문 궤적, 요약, insight, 코드 스킬을 구분한다. 각 형태는 검토 가능성·길이·검색성·실행 가능성이 다르다.

## 강사 실전 노트: 경험·스킬 축적

단순 버전:
1. 지금 작업 내용을 `myskill`로 저장한다.
2. 새 세션의 새 작업에서 `myskill`을 불러온다.
3. 이번 작업을 토대로 틀린 점을 고치고 새 내용을 누적한다.

명확화 버전:
1. 다음 작업에도 쓸 수 있는 내용만 `.claude/skills/myskill/SKILL.md`에 저장한다.
2. 각 항목에 어떤 오류나 테스트 결과에서 나왔는지 근거와 날짜를 기록한다.
3. 새 세션에서 `/myskill`을 불러왔는지 확인한다.
4. 테스트 실패·오류 메시지·사용자의 정정처럼 확인된 증거가 있을 때만 내용을 수정하거나 폐기한다.
5. 폐기 이유와 확인 횟수를 남기고, 길이 상한을 둔다.
