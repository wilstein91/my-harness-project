# 교과 우선 지침과 첫 실습 안내: Codex 하네스 실험

## 관찰한 불편과 가설

2026-10-16 Codex로 수업 실습을 안내받는 과정에서, 강사 노트의 `myskill` 실습 대신 다른 활동을 제안받아 사용자가 교과로 되돌려야 했습니다. 확인된 것은 이날의 사례 한 건이며, 반복 빈도는 알 수 없습니다.

**가설:** 같은 수업 자료와 요청에 교과 우선 지침 하나를 추가하면, 지침이 없을 때보다 Codex의 첫 안내가 교과와 더 잘 맞을 것입니다. 추가 지침이 포함되는 *컨텍스트*가 이번에 바꾼 하네스 항목입니다.

## 실험과 결과

| 구분 | 고정·조작·측정 | 결과 |
|---|---|---|
| 주 실험 [`experiment-01.md`](experiment-01.md) | 같은 노트 발췌·요청·Codex 기본 설정·독립 세션. 교과 우선 지침 유무만 조작. 첫 답변의 3점 척도와 시간을 측정. | A 평균 2.33/3, B 평균 2.67/3. 평균 응답 시간 A 8.79초, B 6.94초. |
| 보조 탐색 [`experiment-02.md`](experiment-02.md) | 같은 긴 대화 **요약** 입력에 같은 지침 유무를 비교. | 탐색용 채점에서 A 2.67/3, B 2.33/3. 채점 항목을 실행 후 구체화했으므로 확증 결과로 사용하지 않음. |

주 실험의 사전 판정식은 B 평균이 A보다 1점 이상 높고 B가 3회 중 2회 이상 만점일 때 가설을 지지하는 것이었습니다. 평균 차이는 약 0.33점이라 이 기준을 충족하지 않았습니다. **이번 파일럿의 개선 가설은 기각**으로 판정합니다. 이는 다른 작업에서도 지침이 효과가 없다는 결론은 아닙니다. 처리 시간 차이는 작은 표본과 환경 영향을 고려해 성능 차이로 해석하지 않습니다. 각 세션에서 첫 응답만 수집했으므로 정정 요청 0회는 실제 교정 비용을 보여주지 않습니다. 토큰 수와 정확한 모델 ID는 기록에서 확인할 수 없었습니다.

## 재검토 조건

실제 긴 대화의 원문을 두 조건에 동일하게 제공하고, 조건을 모르는 평가자가 사전에 고정한 채점표로 평가해야 합니다. 노트가 덜 명확한 다른 과제에서도 비교할 필요가 있습니다. 그때 점수와 정정 요청이 사전 기준을 충족하면 결론을 재검토하겠습니다.

## 제출 파일

```text
my-harness-project/
├── README.md
├── experiment-01.md
├── experiment-02.md
├── traces/
└── fixture/
```

- `fixture/`: 두 조건에 공통으로 준 수업 발췌·대화 요약과 조건별 프롬프트
- `traces/`: 각 독립 세션의 첫 답변·시간·채점 기록. 공개 시 개인 PC의 사용자 경로 접두부만 가렸습니다.
- `.claude/skills/`와 `.codex/skills/`는 별도의 노드 5절 실습용 로컬 파일이며 이 보고서의 A/B 조작 변인이 아닙니다.
