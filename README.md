# 교과 우선 지침과 첫 실습 안내: 내 Codex 하네스 실험

## 내가 겪은 불편과 세운 가설

2026-10-16 Codex와 수업 실습을 하던 중 강사 노트의 `myskill` 실습 대신 다른 활동을 제안받음. 내가 교과 실습으로 돌아가 달라고 정정함. 실제로 확인한 사례는 이날 한 건이며, 같은 문제가 얼마나 자주 생기는지는 모름.

**내 가설:** 같은 수업 자료와 요청에 교과 우선 지침 하나를 추가하면, 지침이 없을 때보다 Codex의 첫 안내가 교과와 더 잘 맞을 것이라고 예상함. 이번에 바꾼 하네스 항목은 추가 지침이 들어가는 *컨텍스트*임.

## 내 프로젝트의 실험과 결과

| 구분 | 고정·조작·측정 | 결과 |
|---|---|---|
| 주 실험 [`experiment-01.md`](experiment-01.md) | 같은 노트 발췌·요청·Codex 기본 설정·독립 세션을 사용함. 교과 우선 지침 유무만 바꿈. 첫 답변의 3점 척도와 시간을 측정함. | A 평균 2.33/3, B 평균 2.67/3. 평균 응답 시간 A 8.79초, B 6.94초. |
| 보조 탐색 [`experiment-02.md`](experiment-02.md) | 같은 긴 대화 **요약** 입력에 같은 지침 유무를 비교함. | 탐색용 채점에서 A 2.67/3, B 2.33/3. 채점 항목을 실행 후 구체화했으므로 확증 결과로 사용하지 않음. |

주 실험에서 결과를 보기 전에 정한 지지 기준은 B 평균이 A보다 1점 이상 높고, B가 3회 중 2회 이상 만점인 경우였음. 실제 평균 차이는 약 0.33점이라 기준을 충족하지 못함. 따라서 **이번 파일럿에서 내 개선 가설은 기각**으로 판정함. 다른 작업에서도 지침이 효과가 없다는 결론까지 내릴 수는 없음.

처리 시간 차이는 표본이 작고 실행 환경의 영향이 있어 성능 차이로 해석하지 않음. 각 세션의 첫 응답만 수집했으므로 정정 요청 0회도 실제 교정 비용을 보여주지 못함. 토큰 수와 정확한 모델 ID는 기록에서 확인할 수 없었음.

## 내가 결론을 다시 살필 조건

실제 긴 대화 원문을 두 조건에 동일하게 제공하고, 조건을 모르는 평가자가 미리 고정한 채점표로 평가할 필요가 있음. 노트가 덜 명확한 다른 과제에서도 비교할 필요가 있음. 그 결과 점수와 정정 요청이 사전 기준을 충족하면 내 결론을 다시 검토하겠음.

## 제출 파일

```text
my-harness-project/
├── README.md
├── experiment-01.md
├── experiment-02.md
├── traces/
└── fixture/
```

- `fixture/`: 두 조건에 공통으로 준 수업 발췌·대화 요약과 조건별 프롬프트가 들어 있음.
- `traces/`: 각 독립 세션의 첫 답변·시간·채점 기록이 들어 있음. 공개 전에 개인 PC의 사용자 경로 접두부만 가렸음.
- `fixture/`와 `traces/`는 당시의 입력·출력 증거임. 내 문체에 맞춰 고치면 실험 기록이 달라지므로 원문을 보존함.
- `.claude/skills/`와 `.codex/skills/`는 별도로 진행한 노드 5절 실습용 로컬 파일임. 이 보고서의 A/B 조작 변인은 아님.
